# Yohaku Companion for Windows

[Yohaku Companion](https://github.com/Innei/YohakuCompanion) 的 Windows 简化版本。

## 安装

支持 Windows 10（1809+）和 Windows 11，运行时需要 Microsoft Edge WebView2 Runtime。

在[Releases](https://github.com/DearVinking/YohakuCompanion-Windows/releases) 页面选择：

- **安装包**：下载以 `-setup.exe` 结尾的文件。
- **便携版**：下载 `YohakuCompanion_<版本>_x64-portable.zip`。
